# astrbot_plugin_dorm_power 宿舍电量监控

查询完美校园（智能水电）宿舍剩余电量，支持多用户自助绑定、多房间、每日定时群播报、低电量提醒。

完整安装与使用步骤见 [USAGE.md](https://github.com/suiren0219/-seed/blob/main/USAGE.md)（若你只拿到了插件安装包，可改用插件内的 `/电量搜校` 与本文档的配置说明）。

## 命令

| 命令 | 说明 |
|---|---|
| `/电量` | 查询自己绑定的房间电量（未绑定则查询管理员配置的默认房间） |
| `/电量绑定 <学校代码> <账号>` | 绑定学校代码与账号（账号为完美校园 outid，一般是身份证号） |
| `/电量房间` | 列出账号在水电系统绑定的房间（带序号和当前电量） |
| `/电量添加 <序号或关键字...>` | 把房间加入监控：`/电量添加`（全部）、`/电量添加 1 2`（序号）、`/电量添加 102`（房间号关键字）、`/电量添加 1栋的a 102`（多个关键字自动缩小范围） |
| `/电量删除 <序号或关键字...>` | 移除已添加的房间，如 `/电量删除 1`、`/电量删除 101` |
| `/电量推送` | 在当前会话订阅每日定时播报（默认 8 点、20 点） |
| `/电量解绑` | 清空自己的绑定数据 |
| `/电量搜校 <账号>` | 自动扫描学校代码（限速跑，先试已知代码池；全量约 10-35 分钟，结果发回当前会话） |

> 写法兼容：指令带不带 `/` 前缀都行；参数和指令名之间可以不空格（`电量删除1`、`电量绑定1000000 123...` 也能识别）；序号和关键字可混用，多个关键字会用空格隔开逐步缩小匹配范围。

## 管理员配置

安装后在管理面板「插件配置」中设置**默认房间**（未绑定用户查询时兜底显示）。面板分四块：

**常用（首屏）**

- **account**：水电系统账号（完美校园 outid，一般为身份证号，不是学号）。支持 `enc:v1:` 密文；留空则由各用户各自 `/电量绑定`
- **customercode**：学校代码（默认 1000000 只是占位；用 `/电量搜校` 探测你学校，或从抓包 URL 的 `customercode=` 取）
- **rooms**：每行一条 `房间名|roomverify`；roomverify 绑定后用 `/电量房间` 查看。仅作未绑定用户的兜底，面板里填了 account 才展开
- **encrypt_key**：加密密钥（留空则读环境变量 `DORM_POWER_KEY` 或仓库根 `.dorm_power_key`）
- **notify_origin**：默认房间的定时播报目标，由 `/电量推送` 自动写入，无需手填

**⏰ 预警与播报**

- **cron_hours**：每日定时播报的小时，逗号分隔，默认 `8,20`
- **warn_threshold**：低电量阈值（度），滑块调，默认 20
- **warn_drop_per_hour**：掉电速率阈值（度/小时），滑块调，默认 5

**🔍 搜校节流**：`scan_qps` / `scan_concurrency` / `scan_max_hits` / `scan_cooldown_minutes`，默认 6 / 6 / 3 / 10

**🛠 接口兜底**：`api_url` / `api_command` / `odd_fields` / `cmd_bind` / `cmd_index` / `cmd_login`，上游改地址、改 command、改字段名时在这里覆盖，不必改代码

普通用户无需管理员配置，直接 `/电量绑定` 自己的账号即可；个人信息只存在服务器本地 `data/config/astrbot_plugin_dorm_power_users.json`。

## 安全与防风控

- **敏感信息加密落盘**：配了密钥后，用户账号（身份证号）和房间信息整个 JSON 加密存储（优先 Fernet/AES，
  没装 `cryptography` 时用内置 PBKDF2 方案）；日志与回执里的账号一律脱敏——首尾各隐 4 位、只留中段
  （`440000200001010000` → `****0020000101****`）。
  未配密钥会明文存储并在启动日志里告警。查看/迁移：`python secure_store.py decrypt <文件>`。
- **搜校不再猛扫**：旧版 24 并发扫 1.3 万个代码，容易被限流/封 IP/触发 WAF。现在默认 6 并发 + 6 QPS + 随机抖动，
  连续失败会自动冷却，多次熔断直接中止并提示；同时维护「历史命中过的学校代码」候选池，多数情况下几十个请求就能命中。
- **连接复用与退避重试**：全插件复用一个 aiohttp session（连接池 + keep-alive），
  网络错误 / 429 / 5xx 按指数退避重试；接口返回失败（`result_ != true`）不重试也不计入熔断——那是业务结果，不是网络故障。
- **响应容错**：`body` 是 JSON 字符串或对象、电量字段改名、首个模块不含电量时都能照常解析，并在识别不出结构时给出干净的错误原因。

## 数据来源

接口 `POST https://xqh5.17wanxiao.com/smartWaterAndElectricityService/SWAEServlet`，
command `JBSWaterElecService`，核心 cmd：`h5_getstuindexpage`（电量详情：modlist[0].odd/todayuse/weekuselist/sumbuy）、
`getbindroom`（绑定房间）、`login`（搜校探测）。无需登录态。

> 该接口是完美校园的私有协议，随时可能变更。插件已把地址、command、各 cmd 名、电量字段做成配置项，
> 并把解析不出电量时的「结构指纹」记到日志里，便于快速适配；真失效时只能重新抓包。
