# astrbot_plugin_dorm_power

查询完美校园（支付宝小程序「完美校园」智能水电）里的宿舍剩余电量，做成 AstrBot 机器人插件：群里发一句话就能查，支持多用户各自绑定、多房间、每日定时播报和低电量提醒。

仓库里同时保留了一套不依赖 AstrBot 的命令行版本，用于抓包调试、字段适配和定时轮询。

## 特性

- **多用户自助**：每个人 `/电量绑定` 自己的账号，各查各的宿舍，互不干扰；账号与房间信息加密落盘。
- **多房间**：照明和空调分开计费的宿舍可以一次查完，用序号或房间号关键字增删。
- **每日播报**：`/电量推送` 在群里订阅，默认每天 8 点、20 点播报。
- **双预警**：剩余电量低于阈值提醒充值；掉电速率异常（可能有大功率电器）也会单独提醒，速率按相邻记录的间隔折算，避免把隔了十小时的低消耗误报成掉电。
- **接口可配置**：地址、`command`、各 `cmd` 名、电量字段名都能在面板改，上游小改不必改代码。
- **防风控**：全项目复用连接池，网络错误 / 429 / 5xx 指数退避重试；搜校限速 + 熔断，接口返回业务失败不重试。
- **离线可测**：加密存储、历史去明文、限速熔断、字段容错、插件加载都有不联网的测试，见下方「测试」。

## 命令

| 命令 | 说明 |
|---|---|
| `/电量` | 查询自己绑定的房间电量（未绑定时回退到管理员配置的默认房间） |
| `/电量绑定 <学校代码> <账号>` | 绑定学校代码与完美校园账号 |
| `/电量房间` | 列出账号在水电系统里绑定的房间，带序号和当前电量 |
| `/电量添加 [序号或关键字...]` | 把房间加入监控：不带参数=全部，`1 2`=按序号，`102`=按房间号关键字 |
| `/电量删除 <序号或关键字...>` | 移除房间，如 `/电量删除 1`、`/电量删除 101` |
| `/电量推送` | 在当前会话订阅每日定时播报 |
| `/电量解绑` | 清空自己的绑定数据 |
| `/电量搜校 <账号>` | 不知道学校代码时自动扫描查找（限速跑，结果发回当前会话） |

写法兼容：指令带不带 `/` 前缀都行，参数和指令名之间可以不加空格（`电量删除1`、`电量绑定1000000 123...`）；序号与关键字可混用，多个关键字用空格隔开会自动缩小匹配范围。

## 安装

需要 AstrBot（v3 及以上）和一个已接入的 QQ 机器人。完整步骤见 [USAGE.md](USAGE.md)。

把 `astrbot_plugin_dorm_power/` 目录拷进 AstrBot 的 `data/plugins/`，然后重启 AstrBot。
装之前记得在面板里卸载旧版本，重复上传会报「目录已存在」。

## 管理员配置

在管理面板「插件配置」里填写默认房间（未绑定用户的兜底），普通用户不需要。常用项：

- `account` / `customercode`：水电账号（完美校园 outid，一般是身份证号）与学校代码
- `rooms`：每行 `房间名|roomverify`，`#` 开头是说明行，可以不填
- `warn_threshold`、`warn_drop_per_hour`：两条预警的阈值
- `cron_hours`：每日播报小时，默认 `8,20`
- `encrypt_key`：加密密钥，留空则读环境变量 `DORM_POWER_KEY` 或仓库根 `.dorm_power_key`
- `scan_qps`、`scan_concurrency`、`scan_max_hits`、`scan_cooldown_minutes`：搜校节流参数
- `api_url`、`api_command`、`odd_fields`：上游接口变更时的兜底开关

逐项说明见 [USAGE.md 的配置一节](USAGE.md#配置说明)。

## 安全与隐私

- 用户账号（身份证号）和房间信息整体加密落盘（Fernet/AES；没装 `cryptography` 时回退到内置 PBKDF2 方案），日志与回执里的账号一律脱敏：首尾各隐 4 位（`440000200001010000` → `****0020000101****`）。
- 未配置密钥时明文存储，并在启动日志里告警。
- `/电量解绑` 会删除该用户在本地的全部数据。
- 不把第三方接口当自家的用：连接复用、指数退避、搜校限速与熔断，且接口地址/命令名/字段名都可配置。

## 目录结构

```
├── astrbot_plugin_dorm_power/   # AstrBot 插件（唯一完整实现：main.py / _conf_schema.json / secure_store.py / metadata.yaml）
├── power_service.py             # 接口封装（连接复用 / 退避重试 / 容错解析）
├── secure_store.py              # 加载垫片：实现只在插件目录里维护一份，命令行版共用
├── config_loader.py             # 配置加载：${ENV} 展开 + enc:v1: 解密
├── storage.py                   # 历史电量存储（算掉电速率，房间只存摘要）
├── scheduler_job.py             # 多房间查询 + 阈值/掉电速率双预警
├── notifier.py                  # 推送渠道：console / 飞书 webhook / AstrBot
├── cli.py                       # 命令行入口：probe / room / once / poll / watch
├── config.example.yaml          # 配置示例（复制成 config.yaml 使用）
└── tests/                       # 离线单元测试（pytest 直接收集）
```

## 测试

仓库自带不联网的单元测试：

```bash
pip install -r requirements.txt -r requirements-dev.txt
pytest
```

覆盖：加密存储 / 历史去明文 / 接口封装契约 / 字段容错 / 预警速率 / 搜校限速熔断 / 插件参数解析 / 插件加载冒烟。其中 `tests/test_plugin_smoke.py` 防的是「插件能 import 但一条命令都没注册」这类问题：`@register` 贴错类时，语法检查和其余测试都是绿的，只有真加载才看得出来。

在线联调脚本（`test_power.py`、`test_v2_logic.py`）与打包、体检、隐私扫描工具（`pack_all.py`、`check_workspace.py`、`scan_privacy.py`）涉及真实账号配置，仅作者本地维护，不随仓库分发。

## 数据来源与声明

接口为完美校园私有协议：`POST https://xqh5.17wanxiao.com/smartWaterAndElectricityService/SWAEServlet`，核心 `cmd` 为 `getbindroom`（绑定房间）、`h5_getstuindexpage`（电量详情）、`login`（搜校探测），无需登录态。接口随时可能变更，项目已把地址、命令名、字段名做成配置项，解析不出电量时会记录不含值的「结构指纹」便于适配。

本项目仅供个人查询本人宿舍用电情况使用，请勿用于批量采集或对外提供查询服务；由此产生的账号或接口风险由使用者自行承担。
